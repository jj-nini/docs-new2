# Spaced Repetition — 복습 일정 규칙

복습 계산은 `tools/study.py`가 한다. 이 문서는 그 규칙을 설명하며, 코드와 다르면 **코드가 기준**이다.

## 응답 품질 q (정오 × 확신도)

| | 확실 | 애매 | 찍음 |
|--|------|------|------|
| 맞음 | 5 | 4 | 3 |
| 틀림 | 0 | 1 | 2 |

- 확신 오답(q=0)이 가장 낮다. 잘못 굳은 개념은 모르는 것보다 위험하기 때문이다.
- 찍어서 맞힘(q=3)은 "맞음"으로 치지만 간격이 짧게 잡힌다.

## 간격 계산 (SM-2 변형)

```
q < 3  → reps = 0, interval = 1일, lapses += 1
q >= 3 → reps += 1
         reps == 1 → 1일, reps == 2 → 3일, 이후 → round(interval × EF)
EF' = max(1.3, EF + 0.1 − (5−q)·(0.08 + (5−q)·0.02))   # 초기 EF 2.5
due = 오늘 + interval
```

간격은 대략 1 → 3 → 7~8 → 18~20 → 45일로 늘어난다 (에빙하우스 1·3·7·14·30일과 비슷).

## `local/topics/<slug>/srs.json`

```json
{"q002": {"ef": 1.96, "interval": 1, "reps": 0, "lapses": 2, "due": "2026-10-15",
          "history": [{"date": "2026-10-12", "correct": false, "confidence": "sure", "q": 0}]}}
```

- `lapses` 2 이상 → 반복 오답. 오답노트에서 🔴 후보.
- `due` ≤ 오늘 → 오늘 복습 대상. `study.py due`가 이것부터 고른다.
- 문항이 srs.json에 없으면 아직 안 푼 새 문항이다.

## 오답노트의 복습 표기

- 기록 줄: `✗ 10-12 · ✗ 10-14 · ✓ 10-15 · 다음 복습 10-18`
- 연속 3회 맞음(그중 마지막이 확실) → `(졸업)` 처리.
- 주제 홈 `## 학습 현황`에 "오늘 복습 N문항 · 이번 주 M문항"을 쓴다 (`stats`의 `due_today`, `due_week`).
